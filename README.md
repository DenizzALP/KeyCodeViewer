# KeyCode Display

This is a small web project that displays the name and key code of any key pressed on the keyboard. It is built using HTML, CSS, and JavaScript.

## Features

- Detects and displays the key name and key code when a key is pressed
- Highlights the pressed key visually
- Responsive and minimal layout

## How It Works

When you open the page, it prompts you to press any key. Once a key is pressed:
- The key's name is shown
- Its key code (numeric value) is displayed

If the spacebar is pressed, it is shown as "space".

## Usage

1. Clone the repository:

    ```bash
    git clone https://github.com/DenizzALP/KeyCodeViewer.git
    cd Guncel-Hava-Durumu-Uygulamasi
    ```
2. Open the `index.html` file in your browser.

3. Press any key on your keyboard and see the result.

## Technologies Used

- HTML
- CSS (Flexbox)
- Vanilla JavaScript (DOM Events)
